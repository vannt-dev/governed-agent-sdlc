# Release plan

## Outcome

Version 0.6.0 is tagged, released on GitHub and published to PyPI, and installs from the registry.

## Task graph

1. Update `pyproject.toml`, `src/agentkit/__init__.py`, `CHANGELOG.md`, and `README.md` for 0.6.0.
2. Verify validator/full tests, build wheel/sdist, and install the wheel in an isolated consumer.
3. Record review and QA evidence under `docs/agent/`.
4. Commit/push `release/public-20261012`, open a PR, wait for CI, and merge the verified head.
5. Tag the merged commit `v0.6.0`; verify GitHub assets and dispatch existing PyPI publishing.
6. Install registry version 0.6.0 in an isolated consumer and record any external blockers.

## Ordering rationale

Each step uses the result of the one before it: the tag must equal the package version, the GitHub
Release is built from the tag, and PyPI publishes the assets of that release.

Write scope is the four release files above and this task's specification, plan, task, review and
QA records. Existing source functionality and release workflow remain unchanged.
